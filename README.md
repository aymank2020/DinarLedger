# DinarLedger

Multi-currency subscription billing & IFRS 15 revenue recognition engine.

A Python library, currently in early development.

## Status

Pre-alpha — APIs are not yet stable.

## Goals

- Subscription lifecycle and per-seat pricing
- Multi-currency invoicing with FX support
- IFRS 15 / ASC 606 revenue recognition
- Decimal-based monetary arithmetic throughout
